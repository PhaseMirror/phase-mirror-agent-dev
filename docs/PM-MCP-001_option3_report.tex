\hypertarget{reported-not-on-that-ref}{%
\subsection{Reported, not on that ref}\label{reported-not-on-that-ref}}

The report says the root \texttt{Cargo.toml} members were restored to
\texttt{{[}"crates/*",\ "xtask"{]}},
\texttt{phase-mirror-agent/Cargo.toml} again has a
\texttt{{[}workspace{]}} directive, and
\texttt{phase-mirror-mcp/src/tools/prismpm\_actions.rs} wraps a
\texttt{prismpm} process for:

\begin{itemize}
\tightlist
\item
  \texttt{prismpm\_model\_check}
\item
  \texttt{prismpm\_generate}
\item
  \texttt{prismpm\_verify}
\item
  \texttt{prismpm\_evidence\_read}
\end{itemize}

routed from \texttt{legacy\_tool\_handler} and advertised in both
initialize responses.

On the published tree, \texttt{phase-mirror-mcp/src/tools/} contains
\texttt{evaluate\_esi\_risk.rs}, \texttt{governed\_bridge.rs},
\texttt{litigation\_scan.rs}, \texttt{llm\_generate.rs},
\texttt{mod.rs}, \texttt{spoliation\_check.rs},
\texttt{stability\_witness.rs}, and \texttt{verify\_ledger.rs}.
\texttt{prismpm\_actions.rs} is absent. A code search for
\texttt{prismpm\_model\_check} and \texttt{prismpm\_evidence\_read}
returns nothing on UOR-Foundation or PhaseMirror. There is no root
\texttt{Cargo.toml} on that ref. \texttt{phase-mirror-agent/Cargo.toml}
does contain an empty \texttt{{[}workspace{]}} table; that line alone
does not show a revert.

The published MCP crate also depends on
\texttt{../../../Foundry/tests/verification-harness}, a path outside the
repository. That tree does not build as a closed workspace.

\hypertarget{what-would-close-the-joint}{%
\subsection{What would close the
joint}\label{what-would-close-the-joint}}

Process invocation is the right shape only if the unpublished file does
all of the following:

\begin{itemize}
\tightlist
\item
  The \texttt{prismpm} binary is the one named by \texttt{prismpm.lock}
  in the digest-pinned devcontainer, not the first \texttt{prismpm} on
  \texttt{PATH}.
\item
  The argument vector is a closed set. A tool does not accept a
  free-form subcommand.
\item
  \texttt{prismpm\_evidence\_read} reads only the evidence directory the
  lock names. An arbitrary path is a socket the joint does not have.
\item
  The MCP binary links no PrismPM crate and contains no compiler
  methodology of its own.
\item
  A plant that points the tool at a different binary, or that asks
  \texttt{evidence\_read} for a path outside the evidence directory,
  fails.
\end{itemize}

Until that file is on a published ref and those plants exist, Option 3
is the adopted joint and not a landed implementation.
