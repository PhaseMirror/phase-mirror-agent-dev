# Security Policy

## Supported Versions

Currently, the Phase Mirror agent is under active development. Security updates will be applied to the `main` branch. 

## Reporting a Vulnerability

If you discover a security vulnerability within the Phase Mirror Agent or MCP server (such as path traversal flaws in evidence reading or unauthorized execution escapes), please do **not** open a public issue.

Instead, please send an email to the security team of the UOR Foundation or the maintainers directly. You will receive a response within 48 hours acknowledging receipt of the vulnerability.

We take the security of our isolated agent boundaries very seriously. Vulnerabilities regarding the MCP tool boundaries (Option 3 constraints) will be prioritized.
